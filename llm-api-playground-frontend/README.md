# LLM API Playground — Frontend

React 19 + Vite + Tailwind CSS v4 client for the LLM API Playground.

```bash
npm install
npm run dev     # http://localhost:5173
```

Set `VITE_API_URL` in `.env` (see `.env.example`) to point at a backend other than `http://localhost:5000`.

See the [main README](../README.md) for the full project documentation: architecture, API reference, security (CORS and rate limiting) and setup.
